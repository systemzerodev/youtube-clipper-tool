# 🔐 Security Policy

## 📌 Supported Versions

This project is currently in early development and does not have versioned releases yet.

---

## 🚨 Reporting a Vulnerability

If you discover a security vulnerability, please follow these steps:

1. Do NOT open a public issue
2. Contact the maintainer privately (if contact info is available)
3. Provide detailed information about the issue

---

## 🛠 Scope

Security considerations include:

- Dependency vulnerabilities
- Unsafe file handling
- External command execution (e.g. ffmpeg, yt-dlp)

---

## ⚠️ Disclaimer

This project is under active development and should not yet be used in production environments.

---

## 🔒 Best Practices (For Future)

- Validate all inputs
- Avoid executing unsafe commands
- Keep dependencies updated
- Use environment variables for sensitive data

---

Thank you for helping keep this project secure 🙏
