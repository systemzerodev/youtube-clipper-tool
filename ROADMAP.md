# 🗺️ Roadmap

This roadmap outlines the planned development phases of the project.

---

## 🥇 Phase 1 — Core Clipper (MVP)

Goal: Build a simple and working YouTube clipper

- [ ] Setup FastAPI backend
- [ ] Implement YouTube video download (yt-dlp)
- [ ] Implement video clipping (ffmpeg)
- [ ] Create basic API endpoint (/clip)
- [ ] Test end-to-end clipping flow

---

## 🥈 Phase 2 — Usability Improvements

Goal: Improve user experience

- [ ] Add multiple clip support
- [ ] Add basic preview system (optional)
- [ ] Improve input validation
- [ ] Organize temp & output files

---

## 🥉 Phase 3 — Smart Features (Non-AI)

Goal: Make tool more helpful without heavy AI

- [ ] Auto split video into segments
- [ ] Suggest clip ranges
- [ ] Add preset clip durations (15s, 30s)

---

## 🏆 Phase 4 — AI Integration

Goal: Introduce intelligent clipping

- [ ] Speech-to-text (Whisper)
- [ ] Keyword detection
- [ ] Highlight / hook detection
- [ ] Subtitle generation

---

## 🔁 Phase 5 — Automation (n8n)

Goal: Build workflow-based processing

- [ ] Integrate n8n webhook
- [ ] Automate video analysis pipeline
- [ ] Generate clip suggestions automatically
- [ ] Support batch processing

---

## 🌐 Phase 6 — Frontend

Goal: Create user interface

- [ ] Build web UI (React / Next.js)
- [ ] Display clip previews
- [ ] Enable user selection & editing
- [ ] Download interface

---

## 🚀 Future Vision

- Content automation tool (Shorts / TikTok)
- AI-assisted editing pipeline
- Cloud-based processing
- SaaS platform
